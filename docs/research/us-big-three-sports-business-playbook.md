## 00. 結論先講 · Bottom Line First

- **不要做第二個 ESPN** / Don't build another ESPN：比分、數據 App 是巨頭與官方 App 的主場，且數據授權昂貴。你的優勢是「中文 + 商業解讀 + 帶團經驗」。  
  *Scores and stats are owned by giants and league apps; your edge is Mandarin + business interpretation + tour-guide know-how.*
- **三層產品：免費 → 付費 → 高單價** / Three tiers: free → paid → premium：免費的台灣時間賽程與台灣球員追蹤引流 → 付費「運動商業週報」 → 高單價美國觀賽旅遊（與合法旅行社合作）。  
  *Free Taiwan-time schedules and Taiwanese-player tracking → paid weekly sports-business brief → premium US game trips via a licensed agency.*
- **時機：MLB 勞資協議 12/1 到期** / Timing: MLB CBA expires Dec 1：聯盟預期封館，2027 球季有風險。這是商業內容的流量高峰，也是觀賽旅遊的最大風險——2027 MLB 行程在協議落定前不預售。  
  *A lockout is expected and 2027 is at risk: a content spike, and the reason not to presell 2027 MLB trips until a deal is done.*
- **三條紅線** / Three red lines：① 不用聯盟／球隊 Logo 與比賽影片 ② 不推廣境外博弈（台灣僅運彩合法） ③ 賣行程須由合法旅行社承辦。  
  *① No league/team logos or game footage ② No offshore betting promotion ③ Trips sold only through a licensed travel agency.*

`features/taiwan-time.feature`

```gherkin
Feature: Taiwan-time schedule 台灣時間賽程
  Scenario: Convert a US night game across daylight saving time
    Given a game starts at "2026-11-01 19:10" in "America/New_York"
    When I view the schedule in "Asia/Taipei"
    Then I should see the start time "2026-11-02 08:10"

  Scenario: Postponed game
    Given the game "NYY@BOS 2026-09-20" is marked "postponed"
    When I open today's schedule
    Then I should see "延賽 Postponed" instead of a start time
    And followers of that team should receive one push notification
```

`supabase/migrations/0001_core.sql`

```sql
-- times stored in UTC; display converts to Asia/Taipei
create table leagues (id text primary key, name text);            -- NFL / NBA / MLB
create table teams (id text primary key, league_id text references leagues, name text, city text);
create table games (id text primary key, league_id text, home_id text, away_id text,
  start_utc timestamptz, status text check (status in ('scheduled','live','final','postponed')));
create table players (id text primary key, team_id text, name_zh text, name_en text, is_taiwanese bool default false);
create table follows (user_id uuid, target_type text, target_id text, primary key (user_id, target_type, target_id));
create table trip_inquiries (id uuid primary key default gen_random_uuid(), user_id uuid,
  league_id text, date_from date, date_to date, party_size int, status text default 'new');
alter table follows enable row level security;
alter table trip_inquiries enable row level security;
```

## 06. 風險與對策 · Risks & Mitigations

- **智慧財產權** / IP：不用 Logo、官方影片與照片；自製圖表與文字分析；引用新聞只摘要並附連結。  
  *No logos or official footage; original charts; summarize and link news.*
- **數據授權** / Data licensing：只用授權 API，遵守快取與顯示條款；免費方案多不可商用。  
  *Licensed APIs only; free tiers are often non-commercial.*
- **博弈法規** / Gambling law：不放賠率、明牌、境外運彩連結；廣告主篩選。  
  *No odds, picks or offshore links; vet advertisers.*
- **旅行業法規** / Travel licensing：自己不收團費，由合法旅行社承辦與開立代收轉付；你提供導覽與內容。  
  *A licensed agency sells and collects; you design and guide.*
- **封館與賽程風險** / Lockout & schedule：2027 MLB 行程協議落定前只收候補；所有行程附延賽／取消條款。  
  *Waitlist only for 2027 MLB until a deal; cancellation terms on all trips.*
- **下一步** / Next step：本週：申請資料 API 試用、建立 repo、寫出第一份「MLB 封館懶人包」草稿。  
  *This week: API trial, repo, first lockout explainer draft.*
